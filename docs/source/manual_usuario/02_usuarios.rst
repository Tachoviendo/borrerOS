2. Qué Usuarios Existen
=======================

BorrerOS tiene tres usuarios predefinidos con distintos niveles de acceso:

.. list-table::
   :header-rows: 1
   :widths: 20 20 60

   * - Usuario
     - Rol
     - Qué puede hacer
   * - ``adminso``
     -  Administrador
     - Todo. Tiene acceso a todas las opciones del menú incluyendo
       backup, reportes y apagado del sistema.
   * - ``estudiante``
     -  Estudiante
     - Ver información del sistema, procesos, memoria, disco, crear
       archivos personales, ver logs y usar la gestión de I/O.
   * - ``invitado``
     -  Invitado
     - Solo puede ver información básica del sistema. Acceso mínimo.

.. note::
   Las contraseñas fueron definidas durante la instalación.
   Consultá con el administrador si no las tenés.
